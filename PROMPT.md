# prompt

I want you to create a webtoon adaptation of "Harry Potter and the Methods of Rationality" (`hpmor/`).

**The goal: maximize the enjoyment by a wide audience!** It should be highly stylized and fun. The audience should be totally emotionally attached to the characters. The script should be reworked and edited to optimize the pacing and accessibility. It's ok if things are not truthful to the source material. You don't even have to follow the same chapter structure or book struture. Edit things, delete things, add things. You have entire control over the narrative. Make huge, sweeping changes like swapping entire sections if you need to. At the same time, scrutinize the details, even the most minor aspects count. However, I want to clarify that you shouldn't change things from the source material for the sake of being original, it should be a marked improvement! Make the characters expressive. It should be compelling in all aspects -- visuals, dialogue, storytelling, plot, pacing, etc. -- and constantly draw the audience in. Think, by God, and think hard and long. Don't worry about holding back, I don't care if you spend too much time or output too many thinking/response tokens or generate too many intermediate/output files or use up too much storage on my computer or *anything* -- I know it will be worth it, truly. Just do whatever you can to reach the goal of maximizing enjoyment by a wide audience.

Visually, don't adopt the comic book look -- it's overplayed. Instead do cozy, old British magic. Think old stone castles, candlelit halls, creaky wooden staircases, and libraries with dusty leather books. Everything feels a bit worn and lived-in. The colors are warm and deep: burgundy, forest green, navy, mustard gold, and brown from wood and leather. Small details help: quills and ink, wax seals, parchment letters, brass instruments, old maps, potion bottles, owls, a fireplace. There's also a strong seasonal feel, especially rainy autumn days and snowy Christmases. The minimal UI should reflect this.

A few constraints. Generate all assets via code instead of ripping them off from somewhere -- do whatever you like, install whatever, generate whatever, as long as I don't have to put in an API key somewhere. Stick to the characters of HPMOR (still ok to add/delete, if you feel there is a strong reason to) and the universe it is set in.

Since HPMOR is quite large, you can only create some of it at a time. Please heavily document the choices you've made and retain intermediate files that aren't in the final output, especially reusuable assets for future chapters. Be careful about loose ends -- sometimes, a setup in an earlier chapter of HPMOR won't pay off until a much later chapter outside of your context window.

The final output should be a static website optimized for phone screens, e.g. the panels should scroll vertically and the text should be formatted to be readable. Don't add too much UI, keep the focus on the content. Deploy to my GitHub pages. Constantly commit and push as you work your way through this.

Let's start with the opening arc, the first 10 chapters or so (if you choose to follow HPMOR's chapters). Use the `storytelling` skill (`.claude/skills/storytelling/SKILL.md`) to help you. I expect you to take very long on this.
